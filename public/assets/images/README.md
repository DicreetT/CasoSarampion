# Patient image states

Drop optional PNGs here to replace the SVG fallback in the patient scene.

Expected filenames:

- `normal.png`
- `fever.png`
- `r1.png`
- `dehydrated.png`
- `respiratorydistress.png`
- `critical.png`
- `improved.png`

If a file is missing, the app falls back to the built-in SVG illustration automatically.
